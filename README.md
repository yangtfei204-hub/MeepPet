# 🐾 咪噗 ☆ MeepPet

SillyTavern 桌宠插件 — 一只会陪你聊天的可互动桌宠。

## 功能

- 🍖 投喂 / 🛁 洗澡 / 🛏️ 睡觉 互动系统
- 💬 独立聊天窗口，支持接入自定义 API 或复用酒馆 API
- 🧠 记忆系统：AI 自动提取记忆、对话总结、增量合并
- 🎨 高度自定义外观：精灵图、主题配色、菜单图标、心情图标
- 🚶 自动闲逛、边缘吸附、拖拽互动
- 📖 支持读取酒馆角色卡描述和世界书
- 🌐 多主题支持（赛博朋克、可爱粉、深海、森林等）
- 📱 移动端适配
