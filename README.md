# 🐾 咪噗 ☆ MeepPet

SillyTavern 桌宠插件 — 一只会陪你聊天、陪你玩游戏的全功能可互动桌宠。

---

## ✨ 功能总览

### 🐱 桌宠核心
- 🍖 投喂 / 🛁 洗澡 / 🛏️ 睡觉 互动系统（饱食/清洁/精力三维状态）
- 🚶 自动闲逛、边缘吸附挂起、拖拽互动（甩晕效果）
- 😊 心情系统：根据状态自动变化（开心/普通/难过/困了/饿了/脏了）
- 🔄 离线衰减 & 回归奖励（离开超过1小时/24小时有不同反应）
- 🎨 17种精灵图状态（闲置/走路4方向/睡觉/开心/难过/拖拽/晕乎/吃东西/洗澡/打招呼/思考/挂起3方向）
- 📐 桌宠缩放（0.5x~2.0x）
- ⚡ 斜杠指令 `/pet status|feed|bath|sleep|summon|toggle|chat`

### 📱 手机界面
- 📱 仿真手机 UI（状态栏/时钟/电量/信号/壁纸）
- 🔒 锁屏系统（动画 + 数字密码 + 悬浮通知）
- 📲 8个内置 App（聊天/设置/主题/书架/通讯录/个人主页/论坛/同人文）
- 📱 4×N 主屏网格，支持最多5页，左右滑动翻页
- 📌 长按进入编辑模式，拖拽排序 App
- 🧩 小组件系统（拍立得/相框/便签/日历/小相框/横幅图/短便签 + 自定义 HTML/CSS 组件）
- 🌤️ 天气显示（基于 wttr.in）
- 🔋 可选读取真实电量

### 💬 聊天系统
- 📇 通讯录：从酒馆角色卡导入或手动创建联系人，每个联系人独立聊天记录和记忆
- 💬 多会话管理：消息列表页，每个联系人独立会话
- 🐾 三种聊天模式：桌宠模式 / 💬 线上模式（|||多条分隔）/ 🌙 线下模式
- 📨 发送消息（不触发回复）+ ➤ 生成回复（触发 AI）
- 😺 表情包系统：上传/发送/编辑/删除，支持右键/长按管理
- 🔄 右键/长按 AI 回复可重新生成
- 🤖 API 自动消息（定时主动发消息）
- 👁️ 多模态视觉识别（表情包图片发给 AI 看）
- ⏳ 流式输出（逐字显示）
- ⏰ 时间感知（AI 知道当前日期/星期/时段）
- 🔢 Token 实时估算显示

### 🧠 记忆系统
- 📝 对话记录（可调整读取轮数）
- 🧠 记忆条目（手动添加 / 🤖 AI 自动提取，支持标签 + ⭐1~5星优先级）
- 📝 对话总结（手动触发 AI 压缩，支持增量/覆盖/追加三种策略）
- 📚 聊天归档（总结后旧记录自动归档）
- 🏠 小屋专属记忆池（独立于手机聊天）

### 🏠 桌宠小屋
- 🖼️ 沉浸式立绘对话空间（2:3竖屏，房间背景 + 人物立绘）
- ⌨️ 打字机效果 + 关键词表情匹配（AI 回复中出现关键词自动切换立绘）
- 🍖🛁🛏️ 小屋内喂食/洗澡/睡觉
- 🔄 重新生成 / 展开收起对话框
- 👗 换装系统：多套服装，每套独立立绘+动作+表情
- 🎭 小屋专属角色卡/世界书/记忆池（不影响手机聊天）

### 📔 日记系统
- 📅 日历视图 + 快速跳转年月
- ✨ AI 以桌宠视角生成日记（可选记忆范围 + 聊天范围）
- ✏️ 编辑/删除/导出全部日记

### 📰 论坛 & 📝 同人文
- 📰 论坛：AI 根据世界书生成小红书风格帖子 + 评论，支持点赞/收藏/发帖
- 📝 同人文：AI 生成/续写同人文，支持自由发挥或指定剧情走向，评论生成
- 📖 独立世界书配置（论坛/同人文各自可关联不同的世界书）

### 📚 书架
- 📥 导入漫画（图片/ZIP/PDF）和小说（TXT/EPUB）
- 📖 内置阅读器（翻页/进度条/目录/字号调节/沉浸模式）
- 🎨 阅读背景自定义（纯色/背景图/透明度/明暗）
- 🔤 自定义字体（本地文件/网络URL/CSS @import）
- 🔖 书签系统（书签/高亮 + 笔记）
- 🏷️ 标签分类 + 搜索 + 排序 + 网格/列表切换
- 💾 备份/还原书架数据

## 📥 安装

1. 打开 SillyTavern，进入 **扩展 → 安装扩展**
2. 粘贴本仓库地址：https://github.com/yangtfei204-hub/MeepPet.git

3. 安装完成后，屏幕上会出现桌宠，点击桌宠打开菜单开始使用

---

## 🚀 快速上手

1. **配置 API**：点击桌宠 → ⚙️ 设置 → 🔑 API 标签页，填写 API Key 和 Base URL（或选择使用酒馆当前 API）
2. **设定桌宠性格**：💬 聊天 → 打开手机 → 👤 个人主页 → 填写桌宠名字和系统提示词（或选择内置预设）
3. **开始聊天**：💬 聊天 App → 📇 通讯录添加联系人 → 点右上角 ＋ 创建会话 → 输入消息发送

## 📦 数据存储

数据存储在浏览器 IndexedDB 中。

⚠️ **清除浏览器缓存 = 数据丢失！** 请定期使用 ⚙️ 设置 → 💾 数据 → 📤 导出 进行备份。

推荐使用 ☁️ GitHub 图片托管功能，将 base64 图片迁移到 GitHub 仓库以释放本地存储空间。
